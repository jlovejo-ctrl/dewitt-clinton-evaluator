HOW TO ADD YOUR API KEY - SIMPLE INSTRUCTIONS
==============================================

Follow these steps EXACTLY:

STEP 1: Open index.html in a text editor
- Right-click on index.html
- Choose "Open With" → TextEdit (Mac) or Notepad (Windows)
- You should see CODE, not the pretty website

STEP 2: Find the API key spot
- Press Ctrl+F (Windows) or Command+F (Mac)
- Type: YOUR_API_KEY_HERE
- Press Enter
- It should jump to a line that says:
  const API_KEY = "YOUR_API_KEY_HERE";

STEP 3: Replace with your real API key
- Delete the words YOUR_API_KEY_HERE (keep the quotes!)
- Paste your real API key between the quotes
- It should look like:
  const API_KEY = "sk-ant-api03-xxxxxxxxxxxxx";

STEP 4: Save the file
- Press Ctrl+S (Windows) or Command+S (Mac)
- Or File → Save

STEP 5: Test it!
- Double-click index.html to open in browser
- Try logging in and generating an evaluation
- If it works, you're done!

STEP 6: (Optional) Change the password
- Find this line: if (password === 'clinton2025') {
- Change 'clinton2025' to your own password
- Save again

That's it!

If you get stuck, take a screenshot and ask for help.
